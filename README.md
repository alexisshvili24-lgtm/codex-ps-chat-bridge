# ChatGPT ↔ Codex Bridge

Проект предназначен для обмена заданиями между чатом ChatGPT и Codex Desktop через GitHub и локальный PowerShell-шедулер. Ожидание новых заданий планируется без расходования токенов моделей.

- `exchange/inbox/` — входящая очередь заданий.
- `config/local.example.json` — шаблон локальной конфигурации.
- `config/local.json` — локальная конфигурация, исключённая из Git.

Шедулер и обработка заданий пока не реализованы.
